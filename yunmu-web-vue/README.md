# 云牧智感 - Vue 2.7 + Vite 前端项目

## 技术栈
- **Vue 2.7** (最终版，支持 Composition API)
- **Vite 5** (构建工具)
- **Element UI 2.15** (UI 组件库)
- **ECharts 5.4** (图表)
- **高德地图 JS API 2.0** (地图)

## 快速开始
```bash
npm install
npm run dev
```

## 项目结构
```
src/
  main.js            # 入口文件
  App.vue            # 根组件（布局框架）
  assets/css/        # 全局样式
  components/
    layout/          # 布局组件 (Header, Sidebar)
    tabs/            # 功能页组件 (Overview, Animals, Location...)
  utils/             # 工具函数、API、模拟数据
```
